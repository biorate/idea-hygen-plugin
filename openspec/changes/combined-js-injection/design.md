# Design

## Context

`HygenEjsIslandInjector` — `MultiHostInjector` для `HygenEjsIsland`, по одному `addPlace` на остров → по одному JS-документу на остров. `HygenEjsPrelude` + `HygenEjsPlaceholderInjector` уже реализуют placeholder-prelude механизм (рефлексия над `MultiHostRegistrarPlaceholderHelper`), но применяется он по-островно. `HygenMultiHostInjector` инжектит тело шаблона в host-язык отдельно. Спеки `hygen-ejs-injection`, `hygen-template-context` задают текущий контракт.

## Goals / Non-Goals

**Goals:**
- Один JS-документ на файл шаблона; скобки и объявления связываются между островами.
- Prelude (`h` + контекст) — один раз на файл.
- Никаких новых ложных ошибок и никакого падения на битых шаблонах (graceful degradation сохраняется).

**Non-Goals:**
- Резолв через placeholder для `h.*` (путь `MultiHostRegistrarPlaceholderHelper` для синтетических деклараций) — уже существует, не расширяем.
- Mirror-target assist, dry-run и прочий backlog.
- Форматирование/парсинг JS между островами как «настоящего» файла.

## Decisions

1. **Хост инъекции — `HygenFile`.** `elementsToInjectIn()` возвращает `HygenFile`; один `startInjecting` → `addPlace` для каждого острова (range относительно файла) → `doneInjecting`. Платформа создаёт один injected-документ, places конкатенируются. Альтернатива (по островам с общим InjectedLanguage) платформой не поддерживается.
2. **Prelude — первый place файла.** Через `HygenEjsPlaceholderInjector` вставляем текст prelude в range `[0,0)` файла (или в начало первого острова, если платформа отвергает нулевой range). Если helper недоступен — деградируем до инъекции без prelude (как сейчас при отсутствии JS-плагина: ошибок не добавляем, только теряем синтетику).
3. **Пустые/комментарные острова пропускаются** — range не регистрируется, поведение `islandCodeRange()` переиспользуется как есть.
4. **Закрытые острова (unterminated) не инжектятся** — они не образуют `HygenEjsIsland`; остальные острова файла инжектятся независимо, что сохраняет graceful degradation.
5. **Spike-first:** первая задача — прототип в реальной IDEA 2025.2: (a) скобки через острова не дают ошибок, (b) prelude на нулевом range работает, (c) typing в острове не ломает инъекцию, (d) нет дубликатов деклараций при нескольких островах. Если нулевой range невозможен — prelude уходит в первый остров (fallback), это фиксируется в design перед остальной реализацией.
6. **Удаление `HygenEjsIslandInjector`** после включения нового инжектора; тесты переориентируются на файловый сценарий (имена тестовых классов можно сохранить).

## Risks / Trade-offs

- **Платформенная хрупкость**: multi-place инъекция на host-уровне — рабочая механика (используется в `HygenMultiHostInjector`), но interplay с `HygenEjsReferenceContributor` и completion требует проверки в IDE.
- **Ошибки между островами станут «настоящими»**: если один остров открывает скобку, а закрывающего нет вообще — ошибка теперь честная (раньше было две фантомных). Это желаемое поведение, но может выглядеть как регрессия на битых шаблонах.
- **Производительность**: один инжект на файл дешевле, чем N инжектов; риск минимален.
- **Откат**: старый `HygenEjsIslandInjector` можно вернуть точечно, т.к. регистрация — одна строка в `plugin.xml`.
